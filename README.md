# leads-background
# 外贸客户深度尽调 Skill
>适配工具：各个常用Agent Skill
>文件名称：SKILL.md（严格大小写，导入识别必需）

## ✨功能介绍
1. 海外品牌客户深度商业尽调，供应链情报调研
2. **自动读取当前对话上下文**，判断是否已经提供目标产品品类
3. 无品类时自动提示：请告知本次需要对接的核心产品品类
4. 仅检索**近2年**品牌ESG/供应链透明度报告，提取Tier‑1、Tier‑2工厂清单
5. 每一家工厂输出契合度判定：高度契合 / 部分契合 / 不契合
6. 自动检索LinkedIn关键采购、供应链决策人
7. 海关提单采购数据分析、同行竞品情报、风险&业务开发建议
8. 末尾附带全部检索来源链接，方便人工核验情报真实性

## 🔄 一键更新（获取新版）
>作者推送新版本后，本地副本**不会自动更新**，需手动同步一次。
仓库里自带更新脚本，运行后会自动从 GitHub 拉取最新 `SKILL.md` 与 `README.md` 覆盖本地。

**macOS / Linux**（在 skill 文件夹内执行）：
```bash
bash update.sh
```
或在文件夹里双击 `update.sh`（需允许终端执行）。

**Windows**（在 skill 文件夹内用 PowerShell 执行）：
```powershell
powershell -ExecutionPolicy Bypass -File update.ps1
```

脚本会先比对本地与远端字节数：**已是最新会自动跳过**（不浪费下载），有新版本才覆盖。完成后**重启 WorkBuddy 对话**即可加载新版本。
若提示「文件异常小」，多为网络受限，请换网络后重试。

## ⚠️重要注意事项
1. 文件名**必须为 SKILL.md**，小写skill.md无法被Trae识别导入
2. 更新Skill内容后，**Raw链接不会变化**，Trae内重新导入一次即可刷新新版
3. 仅读取**当前对话上下文**，不会跨历史会话记忆品类，每次新对话需要重新说明产品
4. 所有Tier工厂信息仅摘抄品牌官方公示内容，**不做任何产能、员工数量估算**

## ❓常见问题
Q：导入一直失败？
A：检查链接是否为【Raw原始链接】，不要复制github仓库首页网址。
Q：为什么一直提示我提供品类？
A：新开对话不会记忆上一轮的品类，需要在**本次对话**告知目标产品。
Q：查不到Tier工厂名单？
A：很多海外品牌不会公开完整供应商清单，报告将会标注【未公开完整Tier名单】，属于正常情况。
